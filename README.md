# DOCTOR SPACE: Crew Health Center (concept prototype)

One static site. No install, no build, no API key. Open `index.html` to run it.

Files: `index.html` (the whole app) and `echo_pad_set.pdf` (printable pad sheet).

## Publish free: Cloudflare Pages (fastest)
1. Create a free Cloudflare account, open Workers & Pages, choose Create, then Pages.
2. Choose Direct Upload and drag in the `doctor_space` folder (or its zip). The dashboard wording may change.
3. Deploy. Leave build command and framework empty.

## Publish free: GitHub Pages (also gives you a public code link)
1. Create a public repository, for example `doctor-space`.
2. Upload `index.html` and `echo_pad_set.pdf` to the root.
3. Settings, Pages, Deploy from a branch, `main` and `/ (root)`, Save.

## Before you submit
- All data, images and values are simulated and labeled as such in the app.
- Declare any AI tools you used in the Space Apps submission form, as the submission guide asks.
- Add the exact NASA pages or data you used to your project description.
- Not a medical device. Doses, kit contents, limits and procedures are placeholders.
